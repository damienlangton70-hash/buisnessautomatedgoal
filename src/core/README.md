# Core

The core is deliberately deterministic and auditable. External AI providers and market-data adapters should feed evidence into these functions rather than owning business decisions directly.

## Safety boundaries

- No autonomous banking or payment-account creation.
- No secret values committed to Git.
- No deceptive reviews, spam, impersonation, or artificial engagement.
- No spending without an explicit authorised budget.
- Every product experiment must have measurable success/kill criteria.
